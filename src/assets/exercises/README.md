# Картинки упражнений

Имя файла — идентификатор упражнения из `src/db/seed.ts` или `src/db/catalog.ts`,
например `db-bench.webp`. По этому имени приложение и находит картинку;
ничего регистрировать вручную не нужно.

Класть сюда готовые файлы руками не надо — прогони исходники через
`node scripts/import-images.mjs <папка>`: он пережмёт до 640px, переведёт
в WebP и проверит, что имя совпадает с реальным упражнением.
