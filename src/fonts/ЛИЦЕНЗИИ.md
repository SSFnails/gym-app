# Лицензии шрифтов

- **Golos Text** — ParaType, SIL Open Font License 1.1
- **JetBrains Mono** — JetBrains, SIL Open Font License 1.1

Оба шрифта распространяются свободно, включая вложение в приложения,
при сохранении лицензии. Файлы получены с Google Fonts скриптом
`scripts/fetch-fonts.mjs`; оба вариативные — один файл на все начертания.
