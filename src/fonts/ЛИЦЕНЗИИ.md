# Лицензии шрифтов

**Manrope** — Михаил Шаранда, SIL Open Font License 1.1.
Свободно распространяется, включая вложение в приложения, при сохранении лицензии.

Файлы получены с Google Fonts скриптом `scripts/fetch-fonts.mjs`.
Шрифт вариативный — один файл на все начертания, вес задаётся осью в `@font-face`.
