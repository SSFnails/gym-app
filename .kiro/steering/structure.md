# Где что лежит

```
src/
  db/
    types.ts       типы всех сущностей
    db.ts          схема Dexie и миграции
    seed.ts        программа владельца: дни и упражнения
    catalog.ts     замены упражнений с коэффициентами пересчёта веса
    movements.ts   пул движений для сборки программы под человека
    init.ts        открытие базы и заливка сида
  lib/
    progression.ts ЯДРО: что ставить на следующую сессию
    anthro.ts      стартовые веса по полу, возрасту, росту, весу, стажу
    generator.ts   сборка программы на 2, 3 или 4 дня
    session.ts     жизненный цикл тренировки, возобновление
    variants.ts    применение замены упражнения
    program.ts     очередь дней, номер недели, разгрузка
    history.ts     графики, откат после перерыва
    backup.ts      выгрузка и загрузка данных одним файлом
    images.ts      картинки упражнений
  routes/          экраны: Home, Workout, Summary, Progress, Settings
  components/      Chart, TabBar, Toggle, Pictogram
  styles/global.css  вся тема одним файлом: токены, панели, кнопки
  assets/exercises/  картинки, имя файла = идентификатор упражнения
scripts/           инструменты проверки и обслуживания
docs/              брифы и промты
```

## Соглашения

- относительные импорты **с расширением** (`./foo.ts`) — так их запускает Node
  напрямую, без сборки;
- комментарии на русском, объясняют **почему**, а не что;
- новые цвета и размеры — только через переменные в `global.css`;
- в списках упражнений показывается `shortName`, на экране упражнения — полное имя.
