# Профили: устройство

## Данные

`Profile` уже описан в `src/db/types.ts`. В `Settings` уже есть `activeProfileId`.

Нужна таблица `profiles` и **разделение по профилю** тех таблиц, где копятся
личные данные:

- `exerciseState`, `sessions`, `setLogs`, `exerciseResults`, `bodyWeight`,
  `measurements` — добавить поле `profileId`;
- `days` и `exercises` тоже становятся профильными: у разных людей разные программы.

### Миграция

Схема сейчас на версии 4. Новая версия 5:

1. создать профиль владельца из известных данных: мужчина, 2005 год рождения,
   190 см, 67 кг, стаж 2 года «непрерывных», три дня в неделю, всё оборудование,
   ограничения `knee`, `wrist`, `lowback`, источник `seed`;
2. проставить всем существующим строкам его `profileId`;
3. записать его в `settings.activeProfileId`.

Ничего не удалять. Миграция обязана быть безопасной для уже накопленных данных —
это единственная копия дневника, бэкапа в облаке нет.

## Экраны

### Создание профиля

Пошагово, по одному вопросу на экран — так меньше страха, чем от длинной анкеты:

1. имя;
2. пол и год рождения;
3. рост и вес;
4. стаж непрерывных тренировок;
5. сколько тренировок в неделю;
6. что есть в зале (список оборудования, множественный выбор);
7. ограничения по здоровью (список из `LIMITS` в `movements.ts`, можно ничего);
8. итог: собранная программа с посчитанными весами, кнопка «начать».

На последнем шаге показать оговорку о точности расчёта и, если стаж меньше года,
усиленное предупреждение.

### Настройки

Новый блок «Профиль» сверху: активный профиль, переключение, создание, удаление,
и действие «пересчитать веса под мои данные» с предпросмотром «было → станет».

## Что переиспользовать

- `generateProgram(profile)` → `{ days, exercises, gaps }`, детерминированно;
- `estimateWeight(movement, profile)` → стартовый вес;
- `LIMITS` из `movements.ts` — готовый список ограничений с пояснениями;
- `Toggle`, `.chip`, `.panel`, `.btn` из существующей темы — новых компонентов
  плодить не нужно.

## Риски

- **Миграция** — самое опасное место. Сначала тест на то, что данные не потерялись.
- **Пустая программа**: если человек отметил мало оборудования, часть слотов
  закрыть нечем. `gaps` для этого и возвращается — показать список.
