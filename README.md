# Дневник тренировок

Личное офлайн-приложение: ведёт тренировку, считает прогрессию и подбирает вес
на следующую сессию. Без бэкенда, аккаунтов и синхронизации — все данные лежат
в браузере телефона.

## Что внутри

- **React + TypeScript + Vite**, PWA с сервис-воркером, работает без сети
- **IndexedDB через Dexie** — единственное хранилище
- Сторонних библиотек в самом приложении нет: графики нарисованы инлайн-SVG,
  шрифты лежат локально, внешних запросов ноль
- Интерфейс только русский, тёмная тема, всё под палец в зале

## Ядро — алгоритм прогрессии

`src/lib/progression.ts`. После каждой сессии считает, что ставить на следующую:

- добрал верх диапазона во всех подходах и остался запас ≤2 → прибавка на шаг
- недобрал низ в двух и более подходах → откат на ступень
- иначе тот же вес, цель по каждому подходу +1 повтор до потолка
- новое движение первые три недели идёт по расписанию, алгоритм молчит
- объём не растёт две сессии подряд → застой, предлагается сброс на −10%

Покрыт тестами: `node --test src/lib/progression.test.ts`.

## Подбор программы под человека

`src/lib/anthro.ts` и `src/lib/generator.ts` собирают программу по росту, весу,
полу, возрасту, стажу, доступному оборудованию и ограничениям по здоровью.

Коэффициенты в `src/db/movements.ts` откалиброваны по реальной программе, а не
выдуманы — тест `generator.test.ts` это проверяет. Честная оговорка: рост и вес
предсказывают силу слабо, решает стаж, поэтому расчёт занижен намеренно и
доводится алгоритмом за одну-две сессии.

## Команды

```bash
npm install
npm run dev -- --host        # разработка, доступно с телефона по локалке
npm run build                # сборка и проверка типов

node --test src/lib/progression.test.ts    # формула прогрессии
node --test src/lib/generator.test.ts      # расчёт весов и сборка программы
node scripts/walkthrough.mjs --sessions=2  # проход тренировки в браузере
node scripts/audit-variants.mjs            # сверка коэффициентов замен
node scripts/shot.mjs http://localhost:4173/#/ out.png --offline
```

Проверки гоняют настоящий Chrome по CDP — сторонних тест-раннеров тоже нет.
