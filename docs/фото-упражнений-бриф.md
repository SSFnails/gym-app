# Бриф: иллюстрации техники для приложения тренировок

Скопируй это целиком в новую сессию Claude Code с доступом к Chrome.

---

## Что за проект

Личное офлайн-приложение — дневник тренировок. Лежит в `/Users/mark/Desktop/gym-app`.
React + TypeScript + Vite, данные в IndexedDB через Dexie, PWA с сервис-воркером.
Сторонних библиотек в приложении нет вообще, графики нарисованы инлайн-SVG.
Язык интерфейса только русский.

Перед работой прочитай `src/db/seed.ts` (программа) и `src/db/catalog.ts` (замены
упражнений) — там лежат все движения и их идентификаторы.

## Задача

К каждому упражнению нужна иллюстрация техники, которая открывается на экране
упражнения во время тренировки. Сейчас там только текстовая заметка.

Всего движений: **86**. Полный список с идентификаторами — в конце брифа.
Что из них уже закрыто, а чего не хватает, показывает `node scripts/audit-images.mjs` —
список в документе устаревает, скрипт считает по данным.

## Жёсткое ограничение, с которого надо начать

**Фотографии упражнений защищены авторским правом.** Нельзя просто найти картинку
в поиске и положить её в приложение — даже в личное. Это первое, что нужно решить,
и от решения зависит вся остальная работа.

Рабочие варианты, в порядке предпочтения:

1. **Свои фотографии.** Владелец снимает себя в своём зале. Ноль вопросов
   по лицензии, и на снимках его настоящие снаряды. Самый правильный путь,
   но требует времени в зале. Спроси, готов ли он.
2. **Открытые базы упражнений.** Проверь через браузер, что именно там сейчас
   и под какой лицензией:
   - `wger.de` — открытая база, у части изображений CC-BY-SA, у части CC0;
     лицензия указана у каждого изображения отдельно, проверять поштучно
   - `github.com/yuhonas/free-exercise-db` — набор с изображениями, лицензия
     указана в репозитории
   - `commons.wikimedia.org` — свободные лицензии, почти всегда требуют указания автора
   Совпадение по названиям будет неполным: русские названия придётся сопоставлять
   с английскими вручную, и часть движений просто не найдётся.
3. **Схемы вместо фотографий.** Рисованные SVG-силуэты: две позиции (начало
   и конец амплитуды), стрелка направления движения. Никаких прав, вес считанные
   килобайты, стиль совпадает с приложением. Для схематичного показа траектории
   этого часто достаточно.

**Не смешивай варианты молча.** Если для части движений нашлись открытые
изображения, а для части нет — так и скажи, и предложи закрыть остаток схемами.

Что бы ни выбрали, на каждое изображение заводится запись об источнике:
файл `src/assets/exercises/CREDITS.json` вида
`{ "<id>": { "source": "<url>", "license": "<название>", "author": "<кто>" } }`.
Без такой записи изображение в проект не кладётся.

## Технические требования

Приложение обязано работать полностью офлайн, поэтому:

- изображения лежат в репозитории, а не грузятся с сети:
  `src/assets/exercises/<id>.webp`, имя файла — идентификатор из таблицы ниже
- формат WebP, длинная сторона не больше 640 px, вес **не больше 40 КБ** на файл
  (85 файлов по 40 КБ — это 3,4 МБ, они уедут в офлайн-кеш вместе с приложением;
  если получается больше, сначала обсуди с владельцем, а не молча раздувай сборку)
- фон тёмный или прозрачный: интерфейс чёрный, белый прямоугольник будет резать глаз
- пересжатие делай через `sips` или `cwebp`, они есть в системе

Подключение к коду:

- в `src/db/catalog.ts` у `VariantDef` и в `src/db/seed.ts` у упражнений добавь
  необязательное поле `image?: string`
- изображения импортируй через Vite (`import.meta.glob`), чтобы они попали
  в сборку с хэшами и в precache сервис-воркера
- на экране упражнения (`src/routes/Workout.tsx`) рядом с названием сделай
  кнопку, открывающую иллюстрацию и текст техники; сейчас там только заметка
  под панелью с весом

## Как проверять

В проекте есть готовые инструменты, пользуйся ими, а не глазами:

```bash
npm run build                                    # сборка и типы
node --test src/lib/progression.test.ts          # формула прогрессии
node scripts/walkthrough.mjs --sessions=2        # проход тренировки в браузере
node scripts/shot.mjs http://localhost:4173/#/ out.png --offline   # снимок и проверка офлайна
node scripts/audit-variants.mjs                  # сверка коэффициентов замен
```

Сервер поднимается через `npm run dev -- --host` или `npx vite preview --port 4173`.

Правила, которые в проекте соблюдаются и которые нельзя нарушать:

- никаких `alert`, `confirm`, `prompt` — они вешают страницу и лезут поверх всего
- никаких сторонних библиотек и внешних запросов в самом приложении
- никакой аналитики и трекеров
- кнопки не меньше 56 px по высоте, шрифт крупный: на экран смотрят потной рукой
  между подходами

## Ограничения по здоровью владельца

Они уже зашиты в данные, и иллюстрации не должны им противоречить:

- разрыв ПКС: глубоких приседов нет и не будет, только до ящика и до параллели
- боль в запястье: жимы со штангой заперты до тумблера в настройках
- поясница: классическая становая с пола не используется, только трэп-бар

Если найденное изображение показывает запрещённый вариант — оно не подходит,
даже если название совпало.
