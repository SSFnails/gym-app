и признак, по которому меряется любое решение. Дальше `.kiro/steering/` (стек
и структура) и `.kiro/specs/profiles/` (последняя выполненная задача).

## Как проверять

Не на глаз, в проекте есть инструменты:

```bash
npm run build
node --test src/lib/progression.test.ts
node --test src/lib/generator.test.ts
node --test src/db/migrate.test.ts
node scripts/walkthrough.mjs --sessions=2      # проход тренировки в браузере
node scripts/shot.mjs <url> out.png --offline  # снимок и проверка без сети
node scripts/audit-variants.mjs                # коэффициенты замен
node scripts/audit-images.mjs                  # чего не хватает из картинок
```

Сервер: `npm run dev -- --host` или `npx vite preview --port 4173`.

## Что легко нарушить

- **никаких `alert`, `confirm`, `prompt`** — вешают страницу; подтверждения делаются
  экраном или двухшаговой кнопкой;
- **никаких сторонних библиотек и внешних запросов** — их нет вообще, и это осознанно;
- **питание не возвращать** — было в исходном замысле, владелец отказался;
- **программу владельца из `seed.ts` не подменять расчётной** — она выверена;
- **ограничения по здоровью — это данные**: колено убирает глубокие приседы,
  запястье запирает штанговые жимы, поясница убирает становую с пола;
- **правки формулы прогрессии — только вместе с тестом**;
- относительные импорты с расширением (`./foo.ts`), комментарии на русском.
